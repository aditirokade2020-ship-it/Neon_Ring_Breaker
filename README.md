# Neon Ring Breaker

A browser arcade game built with plain HTML, CSS and JavaScript (HTML5 Canvas, Web Audio, localStorage). No libraries or build step.

## Files
- `index.html` - screens and layout
- `style.css` - neon styling and responsive layout
- `script.js` - game logic: physics, rings, balls, levels, shop, saving

## Run
1. Keep all files in the same folder.
2. Open `index.html` in a browser, or right-click it in VS Code and choose **Open with Live Server**.

## How to play
- Press Play, then use each ball's card to start it with the play button.
- Every ball has its own speed slider, presets, reset and turn buttons.
- Break all ring segments. Avoid the red balls. Collect coins to spend in the Shop.
- Keys: 1-6 select a ball, arrows turn it, Space pause/resume the ball, P pauses the game.

## Modes
Classic, Challenge (timed) and Endless. Progress, coins, purchases and sound settings are saved in the browser. Use Settings to reset.
